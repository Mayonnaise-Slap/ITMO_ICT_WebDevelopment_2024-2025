Задача¶

Овладеть практическими навыками реализации серверной части (backend) приложений средствами Django REST framework.

1) получить представление о работе с запросами в Django ORM. 2) получить представление об использовании возможностей работы контроллеров и сериализаторов в Django Rest Framework. 3) овладеть навыками написания документации к API.

'Укажите самую позднюю дату владения машиной, имеющую какую-то из существующих моделей в вашей базе'
def get_last_owned_date(car):
    latest_dt_info = (
        Owns.objects.filter(car_id=car)
        .values('car_id')
        .annotate(latest_dt_from_owned=Max('begin_date'))
        .values('latest_dt_from_owned')
    )
    return latest_dt_info

>>> given_car = Car.objects.filter(model='bolt')
>>> for i in given_car:
    print(get_last_owned_date(i))
